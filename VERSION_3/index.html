Featured systems

Security systems that detect, reason and enforce.

Not every build is a product. Several are research into how security should work when software acts on its own.

01

WITNESS

+Evidence-backed admission control for autonomous remediation

A deterministic admission-control layer for autonomous security and AIOps agents. It verifies whether the real environment corroborates an agent's proposed remediation before that remediation executes.

Problem
Agents can generate plausible remediation actions without sufficient evidence that their causal claims are true.
Approach
Separate what an agent claims from what independently observable system state can prove, using deterministic evidence checks before high-impact actions.
Impact
Moves autonomous security from “the AI thinks this is the problem” to “the environment provides sufficient evidence for this specific action.”
AI SecurityAgentic SystemsZero TrustResearch
02

SignalFusion Core

+Security reasoning and attack-path correlation

A detection engineering platform that normalizes telemetry across endpoint, cloud and identity systems, correlates entities across time, and models attacker behavior with MITRE ATT&CK to surface multi-stage and lateral-movement attacks.

Problem
SOCs see thousands of independent signals, while real attacks unfold as sequences across identities, endpoints, applications and cloud infrastructure.
Approach
Correlate signals into behavioral relationships instead of treating every alert as an isolated event.
Impact
Better signal-to-noise, and disconnected alerts become contextual investigations.
DetectionCorrelationSOCMITRE ATT&CK
03

AEGIS

+AI identity and trust control plane

A zero-trust control plane for AI agents. It combines identity validation, intent-aware authorization, policy-based access control and semantic controls against prompt injection and AI misuse, drawing explicit trust boundaries around autonomous systems.

SecureModelGate

+Runtime security enforcement for AI systems

A security enforcement architecture for controlling AI model and agent interactions through deterministic policy, trust boundaries and runtime verification. AI security treated as an enforcement problem, not just a safety discussion.
